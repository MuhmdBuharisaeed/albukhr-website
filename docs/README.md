Before public launch
Verify every company description and statement against approved corporate documents.
Replace the Information Centre placeholder links with approved, public document URLs.
Add a verified official contact channel; do not publish personal details without approval.
Have the disclaimer reviewed by the company's legal adviser.
Test mobile/desktop layouts, keyboard navigation, and all links.
In repository Settings → Pages, select deploy from main branch and /(root).
Add albukhr.com as the custom domain in Pages settings, then apply the exact DNS records GitHub Pages provides. Preserve existing subdomain and mail records.
Enable HTTPS after GitHub confirms the domain and certificate are ready.
This is a plain HTML/CSS/JavaScript site with no build step, backend, analytics, third-party scripts, API keys, or browser storage. Document links are intentionally placeholders and must be connected to approved documents before launch.
